# 个人化备考规划模板（公开方法）

> 来源说明：综合常见 30/60/90 天公考备考节奏，强调“先诊断、再补弱、再模拟”，非付费课程内容。

## 规划前先看统计

生成计划前必须先看个人数据：

- 总做题数、总正确率
- **各模块正确率**（资料分析 / 判断推理 / 言语 / 数量 / 常识 / 政治）
- 近期错题数量与错题模块分布

规则：

- 正确率 < 60% 的模块 = **优先补弱**
- 60%–75% = 巩固 + 限时
- > 80% = 维持性练习，防止回落

## 按天数拆分原则

### 7 天冲刺型

- 每天 1 个弱项模块专项 + 1 组混合题
- 至少 1 次完整限时套卷感觉训练（可拆段）
- 每天固定 20 分钟错题回看

### 14–30 天稳态型

- 周前半：弱项攻坚（资料/判断优先）
- 周后半：混合练习 + 复盘
- 每周至少 1 次模考或半套限时
- 预留 1 天只做错题与方法论回顾

### 60–90 天系统型

1. 诊断期（第 1 周）：摸清模块短板
2. 补弱期：先资料分析与判断推理
3. 提升期：言语语感 + 数量保底策略
4. 模考期：每周套卷，改节奏与蒙题策略
5. 收束期：高频错题 + 常识/时政速记

## 计划文本应包含什么

一份可用的个人计划至少写清：

1. 你的当前数据摘要（不要空谈）
2. 本周期最优先的 1–2 个弱项
3. 每天/每周任务清单
4. 验收标准（例如“资料分析正确率到 75%”）
5. 若某模块已经较强，如何维持而不挤占弱项时间
