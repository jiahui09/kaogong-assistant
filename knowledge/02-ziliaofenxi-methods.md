# 资料分析速算与备考方法（公开笔记）

> 来源说明：整理自常见资料分析公开技巧（基期、增长率、比重、平均数、倍数），仅供个人练习提示。

## 核心公式

- **增长率**：增长量 / 基期量
- **增长量**：现期 × 增长率 / (1 + 增长率)
- **基期量**：现期 / (1 + 增长率)
- **比重**：部分 / 整体
- **平均数**：总量 / 份数
- **倍数**：A / B（注意“多几倍”与“是几倍”的区别）

## 高频坑点

1. **基期比重**与现期比重混淆。
2. **间隔增长率**：`r = r1 + r2 + r1*r2`。
3. **部分增长率高于整体**时，比重上升；低于整体时，比重下降。
4. 材料单位（万/亿、%、百分点）看错直接失分。
5. 综合分析题先做易判断的“能确定对错”的选项，不要按顺序死磕。

## 正确率偏低时怎么练

若资料分析正确率明显偏低，优先这样补：

1. 每天 2 篇材料限时训练（建议 8–10 分钟/篇起步，逐步压缩）。
2. 只练增长 + 比重两类题，先求稳定，再扩到平均数/倍数。
3. 错题按“读材料错 / 列式错 / 计算错 / 选项坑”四类归档。
4. 准备一张个人速算卡：1+r 特殊分数、百分数化分数、截位技巧。

## 考场策略

- 先扫材料结构（时间、主体、单位），再看题。
- 能估算就估算，不必每题精算到个位。
- 遇到计算过繁的题先跳，回头再清。
