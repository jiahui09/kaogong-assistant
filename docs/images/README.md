# 项目介绍配图

- `header.svg`：原创项目题头插画，使用矢量图形，无外链字体、脚本或第三方图像。
- `01-practice.jpg`：真实 Streamlit 套卷作答界面，展示页眉计时、选项作答及重点标记。
- `02-wrong-book.jpg`：真实错题本界面，展示左侧详情/笔记和右侧六列题号目录。
- `03-review.jpg`：真实交卷结果，展示自动批分、错题明细及解析。

截图使用临时 SQLite 数据库中的原创演示题、示例笔记和模拟作答记录，未连接个人用户库，也未调用模型生成规划或解析。界面中的“题库解析”来自原创示例解析，不是上游真题内容。分数、计时和错题数量仅用于演示功能，不构成真实学习成绩或效果承诺。

截图由 Chromium/Playwright 从实际应用页面采集，未重新绘制产品界面。图片经 JPEG 压缩，README 中共三张功能截图，另有一张题头图。配图与本仓库源码采用相同的 MIT 许可。
